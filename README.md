# nixconfig

My NixOS + Home Manager setup, wired together with [flake-parts](https://flake.parts/) and [import-tree](https://github.com/vic/import-tree).

NixOS unstable, `stylix` for theming, `sops-nix` for secrets.

> [!IMPORTANT]
> `flake.nix` is generated by [flake-file](https://github.com/vic/flake-file). After adding or moving modules, run `nix run .#write-flake` instead of editing it by hand.

## Hosts

- `nixgroot` — desktop
- `labnix` — work desktop
- `nixpad` — laptop

### nixpad and LUKS

`nixpad` uses LUKS + BTRFS and asks for the passphrase in the initrd on every boot. If you want TPM2 auto-unlock:

```bash
sudo systemd-cryptenroll --tpm2-device=auto /dev/nvme0n1p2
```

Only do this together with Secure Boot (lanzaboote is set up for that). Without Secure Boot the TPM binds to a boot state that can't detect initrd tampering, so the passphrase stays the safer option. The fingerprint reader still works fine for `sudo`, polkit prompts and screen unlock (`fprintd-enroll`).

## Layout

- `assets/` — wallpapers, icons, avatars
- `modules/` — everything else:
  - `defaults/` — shared NixOS/Home Manager defaults
  - `features/` — opt-in features (browsers, gaming, dev tooling, …)
  - `hosts/` — per-machine configs
  - `settings/` — nix, secrets, stylix, system settings
  - `users/` — user configs

## Rebuilding

```bash
sudo nixos-rebuild switch --flake .#<host>
# or
update   # nh os switch .
```

Update all inputs, then rebuild:

```bash
nix flake update
update
```

Formatting is `nixfmt`:

```bash
nixfmt <files>
```
